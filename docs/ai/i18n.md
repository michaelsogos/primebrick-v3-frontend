# i18n/Translations rule

**CRITICAL: Always add translations immediately when adding labels**

When adding any label text to components, you MUST immediately add the corresponding translation to the i18n files:

- **i18n location**: `src/lib/i18n/`
- **Translation files**: Add the new key to all language files (e.g., `en.json`, `it.json`, etc.)
- **Pattern**: Use the component name as a prefix to avoid conflicts (e.g., `componentName.labelKey`)

**Example:**
```svelte
// Component
<p>{$t('eventToast.title')}</p>
```
```json
// src/lib/i18n/en.json
{
  "eventToast": {
    "title": "Event Title"
  }
}
```
