# i18n/Translations rule

**CRITICAL: Always add translations immediately when adding labels**

## Translation sources

The Primebrick i18n system has **two sources**:

1. **Backend (BE)** — the primary source for ALL translations. The BE serves
   translations as a flat dict (dot-path keys → string values) via the i18n
   API. The FE merges these at runtime via `mergeModuleDict()`. Keys under
   `system.*`, `entities.*`, `shell.*`, and any other non-`app.*` namespace
   come exclusively from the BE.

2. **FE fallback** (`src/lib/i18n/messages/en-GB-fallback.json`) — a flat
   JSON file containing **English-only** translations for keys in the
   `app.*` namespace. This is used when the BE is unreachable (e.g. login
   pages, error pages, public routes). It is NOT a complete dictionary —
   it only covers keys needed before authentication.

### Rules

- **ALL translations are owned by the BE.** When adding a new label, the
  translation key and value MUST be added to the BE's translation system.
- **FE fallback is ONLY for `app.*` keys.** If a new `app.*` key is added,
  it MUST also be added to `en-GB-fallback.json` (English only).
- **Non-`app.*` keys MUST NOT be added to the FE fallback.** They are BE-owned.
- **The FE fallback is English-only.** Never add Italian, French, German,
  Spanish, or Portuguese translations to the FE fallback file.
- **When adding a label to a component**, add the translation key to the BE
  immediately. If the key is under `app.*`, also add it to
  `en-GB-fallback.json`.
- **Never hardcode user-facing text** in components. Always use `$t('key')`.

## Key convention

- Translation keys MUST be `snake_case` singular (see
  `.devin/rules/translation-key-convention.md` for the full convention).
- Keys are flat dot-paths (e.g. `system.settings.config.typeConfig.minLength`).
- The FE dict is flat — `Object.keys($dict)` returns all available keys.

## Example

```svelte
// Component
<p>{$t('system.settings.config.typeConfig.minLength')}</p>
```

```json
// src/lib/i18n/messages/en-GB-fallback.json (ONLY if key is app.*)
{
  "app.auth.login.title": "Sign In"
}
```

```ts
// BE translation system (ALL keys, ALL languages)
// Added via BE i18n management, not in FE code
```
