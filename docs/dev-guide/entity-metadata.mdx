# Entity metadata

Every entity exposes `GET /api/v1/entities/{entity}/meta` — a typed JSON
document that describes how the entity is displayed and what operations it
supports. The canonical type is `EntityMeta`/`MetaColumn` in
`@primebrick/core` (`src/entity-meta.ts`), mirrored verbatim by every
consumer (BE `src/http/entity-meta.types.ts`, FE `src/lib/entity-list/
types.ts`). All fields are snake_case end to end.

**Two layers, one shape.** The `*.meta.ts` file authors the static meta;
`assembleMeta` serves it enriched with runtime-derived members
(`display_name`, `actions`, `collaboration`, `dict`, `relation`) and with
physical facts `withColumnConstraints` derives from the entity class
(`nullable`, `pg_type`, `managed`, `seq.uuid`, …). An author never
restates a derived fact — the binder throws.

For a worked example that exercises nearly every feature of this schema, see
the [ELT case study: job_schedule](./elt-case-study-job-schedules).

## Anatomy

```json
{
  "entity": "user_profile",
  "translation_key": "user_profile",
  "entities_ns": "system",
  "uid": "uuid",
  "display_field": "display_name",
  "display_name": "${display_name}",
  "actions_overrides": {
    "duplicate.bulk": { "enabled": false }
  },
  "create": { "surface": "sheet" },
  "columns": [
    {
      "key": "display_name",
      "label_key": "system.entities.user_profile.fields.display_name",
      "type": "text",
      "order": 0,
      "sticky": true,
      "hideable": false,
      "default_visible": true,
      "sortable": true,
      "searchable": true,
      "filterable": true,
      "nullable": false,
      "pg_type": "varchar",
      "max_length": 100
    }
  ],
  "table": {
    "default_view": "table",
    "default_sort": { "key": "created_at", "dir": "desc" },
    "default_page_size": 25,
    "page_size_options": [10, 25, 50, 100]
  },
  "actions": [
    { "op": "list", "enabled": true, "permissions": ["user_profile.read.all"] },
    { "op": "create.single", "enabled": true, "permissions": ["user_profile.create.single"] },
    { "op": "duplicate.bulk", "enabled": false }
  ],
  "collaboration": { "enabled": true, "expose_editing_value": true }
}
```

## Root properties

| Field | Required | What it does → enables on FE |
|-------|----------|------------------------------|
| `entity` | yes | Entity key, snake_case singular — matches the route segment, the wire entity param, and the `meta.columns` owner. |
| `translation_key` | yes | snake_case singular i18n prefix — composed into `{ns}.entities.<translation_key>.{singular\|plural\|fields.*}` keys. |
| `entities_ns` | no | Namespace **owning** the entity's label keys (default `system`). Module entities point at their own ns (`job` → `job.entities.*`). FE resolves every entity key under it — a wrong ns renders raw keys. |
| `title_key` | no | Bespoke page-title override — **custom pages only**. Absent → FE builds titles from `system.entities.page_title.{list\|create\|edit}` + the entity plural/singular. CRUD metas MUST NOT declare it. |
| `uid` | yes | Column key of the row identity (usually `uuid`). Drives: row keys, `:param` substitution on endpoints, the record-sheet **uid pill** (mono value + copy CTA), ref cells, dirty-close tracking. |
| `display_field` | yes¹ | The primary display column key — sticky identity column, combobox labels, default `display_name` source. Forbidden on `relation` facets. |
| `display_name` | response | `${field}` display template (dot-paths allowed) — titles, chips, ref labels, related-object labels. `assembleMeta` materializes `"${display_field}"` when unauthored. |
| `actions_overrides` | no | Per-op overrides — `enabled` toggles route-backed ops; `label_key`/`icon`/`color`/`confirm_key`/`busy_key` restyle the standard CTA chrome. Never invents ops. |
| `create` | no | Create surface: `"form"` (default) → census `kind:"create"` route → `EntityFormPage`; `"sheet"` → no route needed, the list CTA opens `entity.record` in `mode:"create"` (empty draft, POST on commit). |
| `form` | no | `{validators?: string[]}` — closed-vocab cross-field validator keys attached to the **synthesized** form (the record-sheet fallback). For entities with no authored `page_props.form` route — builtin/platform entities have no route decl to author against. An authored route decl always wins. Applies to create AND update (the merged-row contract is one rule). |
| `columns` | yes | Root-level field dictionary shared by **every** surface (table, forms, filters, pickers, dict pages). See below. |
| `table` | no | `EntityListTable` options — absent on form-only metas (`auth/me`). |
| `actions` | response | Derived capability contract — see below. |
| `collaboration` | response | `{ enabled, expose_editing_value }` — presence SSE + live value sharing on update surfaces. |
| `dict` | response | `@Dict` facet — drives `kind:"dict"` inline-editable pages: `group_field` (fieldset grouping), `order_field` (reorder CTAs), `directional{forward_label_field,inverse_label_field}` (link vocabularies for `@Relation` edges). |
| `relation` | response | `@Relation` facet — directed parent→child edge entity: `parent_field`, `child_field`, `type_field?`, `hierarchical?`. No `display_field`; arc endpoints are immutable after create. |

¹ `display_field` is optional on the wire type but `withColumnConstraints`
**requires** it on every main-entity meta; `relation` metas must not declare it.

## `columns` — the field dictionary

`MetaColumn` describes one entity field. `key`, `label_key`, `type`,
`order` are required on authored entries. **Physical columns are
auto-derived** by `withColumnConstraints` — every `@Column` absent from
`columns` is appended with `default_visible:false` (system columns are
never authored by hand). Authored entries are presentation overrides.

### Identity & layout

| Prop | What it does → enables on FE |
|------|------------------------------|
| `key` | Entity property name — resolves against served columns; unknown keys fail loudly (stale-key metadata invalidation). |
| `label_key` | i18n key of the column label — table headers, form labels, filter names, picker entries. |
| `type` | Cell-renderer discriminator — `text`/`badge`/`boolean`/`color`/`date`/`datetime`/`number`/`sparkline`/`ref`/`ref_count`/`avatar` (open for consumer-registered custom cells). Drives cell anatomy, default searchability, filter operators. |
| `order` | Explicit display position — array position MUST NOT matter. Groups render sticky → normal → audited, each sorted by `order`. Convention: `uuid` = `-1`, `display_field` = `0`. |
| `sticky` | Pinned left in table view — the `uuid` + `display_field` pair by convention. |
| `icon` | Lucide name rendered before the label in **form** field labels — identifies the field's semantic. Absent renders nothing. |
| `color` | Semantic color **token** (`"amber"`, `"amber-500"`) for icon/badge accents — resolved to inline styles. NEVER a `text-*`/`bg-*` class: served meta is invisible to the FE safelist scan — class strings dead-render. |

### Table flags

| Prop | What it does → enables on FE |
|------|------------------------------|
| `sortable` | `false` → ORDER BY disabled, header loses sort affordance. Default `true`. |
| `filterable` | `false` → excluded from the filters sheet. |
| `searchable` | `false` → excluded from the "search in" scope + BE default search. Set false on non-text or sensitive columns. Default `true`. |
| `default_visible` | `false` → hidden initially, still in the column picker. Auto-derived columns default `false` — author the column to show a system column. |
| `hideable` | `false` → the picker can't hide it. |
| `hidden` | **The only total suppression** — drops the column from served meta entirely (no cell, picker, filter, or form). Blocks auto-derivation of the class column too. |
| `audited` | System audit column (`created_at`, `updated_by`, …) — rendered last in every group. Derived from audit/deletable/sync decorators. |
| `kind` | Materialization: absent = physical. `"calculated"` — SQL projection (`@Calculated`), sortable/filterable stay on. `"virtual"` — post-query decoration, sortable/filterable/searchable FORCED OFF. Both are read-only — never in `page_props.form`. |
| `null_label` | `{ label_key, when?{field,equals\|not} }` — replaces `"-"` on null cells **as a red-italic alarm**. Ungated use = false alarms on every empty cell; gate it on a sibling or leave it unset. |

### Derived physical constraints (class facts — authoring throws)

| Prop | What it does → enables on FE |
|------|------------------------------|
| `nullable` | `false` → required in zod + form chrome; `true` → optional. Drives the zod schema `buildEntityFormSchema` builds. |
| `max_length` | From `@Column({length})` → `maxlength` attribute + `z.string().max()`. |
| `pg_type` | Physical PG type (`varchar`, `int8`, `timestamptz`, `jsonb`, …) — informs control pick when `format` is absent; `numericKindOf` maps it to `bigint`/`number`/`decimal` for every numeric surface. |
| `managed` | DB fills the value (`@Key` identity generation). Never client-supplied, never required — excluded from form widgets and write payloads. |
| `default` | Create-form **initial value** — derived from `@Column({defaultSql})` constant literals (typed per `pg_type`: int8 → `bigint`, numeric → `Decimal`), or AUTHORED here as the legal column-level override (covers values not expressible in SQL — e.g. `{seq:{…}}` directives). May also be a `ColumnDefaultSpec` computed spec — closed union, currently `{kind:"next_day_start_local"}` (the form seeds tomorrow 00:00 browser-local; `sequence.default_from` uses it). Volatile expressions (`now()`, `uuidv7()`) are never served. A `placement.default_value` outranks it per-surface; update forms ignore it. |

### Lifecycle

| Prop | What it does → enables on FE |
|------|------------------------------|
| `immutable` | Set-once OR process-derived: **editable on create**, disabled on update, excluded from PUT payloads. Covers authored-once (`idp_username`) and derived (`avatar_initials`) cases. Distinct from `managed`/`audited`. |

### Form semantics (authored input contract)

| Prop | What it does → enables on FE |
|------|------------------------------|
| `format` | **The semantic input discriminator** — picks the control archetype + validation chain before `type` does. See the format vocabulary below. |
| `pattern` | Extra regex on text-ish fields → `z.string().regex()` in the schema. |
| `min_length` | Semantic minimum length (physical `max_length` is derived). |
| `min` / `max` | Numeric bounds for `number`/`money` formats → zod `.min()/.max()` + control clamp. |
| `unsigned` | Rejects `-` in the control AND negative values in wire/form validators. PG has no unsigned — authored only. |
| `uom` | Unit-of-measure semantics on numeric columns — `MetaColumnUom` union: `{kind:'percent'}` (canonical fraction, ×100 display), `{kind:'currency', field}` (per-row ISO code on sibling), `{kind:'<category>', unit}` (fixed Intl unit — `time`/`length`/`mass`/`volume`/`area`/`temperature`/`digital`/`angle`), `{kind:'<category>', field}` (per-row unit, category = picker vocab), `{kind:'custom', field, source}` (custom vocab), `{kind:'custom', symbol}` (fixed suffix). XORs enforced at bind. Absent → plain decimal. |
| `avatar` | `{ color_field, initials_field? }` on `type:"avatar"` — sibling column persists the per-row color; `initials_field` recomputes initials live on edit surfaces. Sibling existence is bind-checked. |
| `json_schema` | `format:"json"` — JSON Schema driving the editor's lint/completion AND structural validation in `buildEntityFormSchema`. |
| `seq` | `format:"sequence"` — sequence-bound column (`@SequenceField`). DERIVED half: `uuid`/`name` (the deterministic bound-row identity `<table>.<field>` — authoring throws). AUTHORED half: `modes` (`"generate"`/`"select"` — which widgets the control offers), `default_mode` (initial mode, default `"generate"`), `allow_create` (new-sequence CTA, default `true`). Wire contract: never a literal — only a `{seq:{…}}` directive resolved in the write transaction. |
| `widget` | Explicit control override — host registry key, bypasses `format`→control derivation on EVERY surface (forms AND filters). |
| `options_source` | Dynamic option vocabulary for combos — closed union: `"census.emits"` (union of modules' `events.emits`), `"census.callables"` (LISTEN subjects), `"audit.actors"` (the table's own audit actors — auto-injected on `*_by` columns), `"system.roles"`. |
| `allow_create` | ComboSelect free-entry flag. `options_source:"census.*"` + `allow_create:true` is a construction error — census sources are closed vocabularies. |

**`uom` sibling-code contract.** A `{kind, field}` uom reads the unit code
from a sibling column — and that code is **always text** (`'kg'`, `'ms'`,
`'EUR'`): no legitimate data model carries a numeric or boolean unit code.
The display narrowing is therefore strict string-only. `''`/`null`/`undefined`
is the legitimate "unit not yet chosen" state (no suffix rendered, no error);
any other non-string value is a modeling mistake and emits a dev-console
error in DEV while rendering no suffix — traced and safe, never silent.

### Dependencies — `depends_on`

ONE declared edge to a sibling column (the pivot) drives this column —
declared once, shared by forms. `withColumnConstraints` enforces legality
(`prop`/`control_prop` need a `type:"ref"` pivot).

| Sub-prop | What it does → enables on FE |
|----------|------------------------------|
| `field` | Sibling column key — the pivot. |
| `filter_field` | `type:"ref"` only: the TARGET column the options `/list` filters on, fed by the pivot's stored value (`country → legal_form` scoped options). Control disabled until the pivot has a value. |
| `disabled_when` | `{equals\|not\|values\|set}` condition — disables the whole control while it matches (`company_dimension` off when `customer_type.code = private`). `set` reads a NON-form sibling via the served row; `set:false` disables while the pivot carries **no** value — the gated-axis pattern (`sequence.default_from`/`revive_slot`/`revive_grace` stay disabled until `revive_every` is filled). |
| `control_prop` | Pivot ROW prop resolving this column's `format` at render time (`contact.value` → `email`/`phone`/`text` from `contact_type.value_kind`). |

`filter_field`/`control_prop` both reset the value on pivot change — a
stale dependent value is a silent integrity leak.

**Pivot scalar contract.** Pivot values are compared and hashed as scalars:
`string`/`number`/`boolean`/`bigint` are the supported pivot types — `bigint`
included because every integer arriving over the wire is bigint by codec
contract (an int pivot, e.g. a year or a numeric enum, is a legitimate
depends_on target). `null`/`undefined`/objects are **not** valid pivot keys:
the dependent treats them as "no pivot value". When a non-scalar pivot value
is detected at runtime, the form degrades safely (no reset cascade) AND a
dev-console error is emitted in DEV — semi-silent by design: the form never
crashes, the console tells you exactly which pivot declaration is wrong, and
the trace leads straight to the metadata authoring mistake. The same contract
applies to `disabled_when` equality tests, which compare cross-type-safely.

### Tooltips

| Prop | What it does → enables on FE |
|------|------------------------------|
| `tooltip` | i18n key of the hint body. |
| `tooltip_title` | i18n key of the tooltip title. |
| `tooltip_priority` | `INFORMATION`/`WARNING`/`ERROR`/`QUESTION`/`HINT`/`SUCCESS` — icon + title color. |
| `show_form_tooltip` | Show on form surfaces. |
| `show_list_tooltip` | Show on list/table surfaces. |

### Type payloads

| Prop | What it does → enables on FE |
|------|------------------------------|
| `ref` | `type:"ref"` — the cell value identifies a row on another entity: `{entity}` static target, `{entity_field}` **lazy ref** (row column carries the target entity per row — one column, N drill targets), `key_field` (drill-key column, default the cell value), `route` (`"detail"`/`"list"`/`"none"` — link target, default detail), `filter_field` (route:"list" filter column), `value_field` (stored value source — `"id"` for true-FK pickers), `presentation` (`"link"` two-affordance anatomy [default] vs `"badge"` legacy pill). Routes resolve through the census — never hardcoded URLs. |
| `reverse_ref` | `type:"ref_count"` — `{entity, filter_field, value_template}`: 1:N badge count linking to the children's filtered list. `filter_field` must be filterable on the target service or the link degrades to plain text. |
| `badge` | `type:"badge"` — `{values: Record<v,{label_key,label_text?,color}>}` per-value label/color mapping. |
| `datetime_iana_toggle` | `type:"datetime"` — `{record_iana_field}`: browser-local vs record-timezone header toggle (IANA id comes from the row). |
| `sparkline` | `type:"sparkline"` virtual column — `{endpoint, request_field, row_key, response_field?, bucket_field?, bucket_unit_field?, series[]}`: the list engine batch-POSTs row keys once per load and renders stacked mini-histograms in every view mode — zero per-page wiring. |

## `format` — the semantic input vocabulary

Closed union (`MetaColumnFormat`) — an unknown format in a `*.meta.ts` is
a compile error. Absent → falls back to `type`.

| Format | Control + validation enabled on FE |
|--------|------------------------------------|
| `text` / `textarea` | Plain / multiline text input. |
| `email` / `url` / `phone` | Format-validated single-line inputs. |
| `secret` | Masked input. |
| `nats_subject` / `service_code` | Governed-reference badge/input — census-resolved module link. |
| `schedule_spec` | Schedule builder + localized prose. |
| `json` | JSON editor — lint/completion from `json_schema`. |
| `display_name` / `idp_name` / `identifier` | Identity-styled text affordances. |
| `color_hex` | Color picker. |
| `number` / `money` | Numeric input (+ `min`/`max`/`unsigned`/`uom`). |
| `date` / `datetime` / `time` | Temporal pickers — `datetime` honors `datetime_iana_toggle`. |
| `snake_key` / `dotted_key` / `dotted_glob` / `slug` / `no_space` | Key-shaped text inputs with grammar validation. |
| `rule_filter` | Rule-filter builder. |
| `lang` | Language picker. |
| `revive_interval` | `ReviveIntervalInput` — dual-mode composite for the `'N unit' \| 'at <ISO>'` canonical: leading mode toggle (interval → `NumericInput` bigint/unsigned + closed 5-unit dropdown `day`/`week`/`month`/`quarter`/`year` — exactly `UOM_DROPDOWN_MAX_OPTIONS`, in-input dropdown, no host picker; literal → `DateWheelPicker` with `includeTime` + timezone bind). Emits `"1 year"` / `"at 2028-06-16T00:00:00.000Z"` — same numeric+uom→text anatomy as `schedule_spec`. Expire axis of `sequence` (`revive_every`). |
| `revive_offset` | Same `ReviveIntervalInput` with `literal="until"` — the grace/switch axis (`revive_grace`): `'N unit'` offset or `'until <ISO>'`. |
| `sequence` | Sequence widget — `modes`/`default_mode`/`allow_create` from `seq`. |
| `sequence_pattern` | Pattern-builder input (`SequencePatternInput`): free literal typing, interpreter-strip preview under the input (schedule-spec convention — `CircleCheck`/`CircleAlert` + rendered example), in-input `Tags` CTA opens the `entity.sequencePattern` token sheet (catalog from `sequenceTokenCatalog`, used-slot `Tags` badge + `-` remove via `removeSequenceToken`, counter padding form, insert-at-caret, borderless token list + display-only preview); validated by `parseSequencePattern` via `checkFieldValue` — same verdict as the wire. |
| `i18n_key` | Translation-key pick — the canonical ComboSelect every key field shares (`i18nKeyOptions`): `*.entities.<translation_key>.rows.*`-scoped vocabulary (broader `.entities.` when `translation_key` is absent), `languages`/`sky-500` icon per option, `custom.*` convention suggestion in `defaultSearch` tracking the row's `code`/`name`, `allowCreate` with `coerceI18nKeyChange` verbatim/scoping rules — the same anatomy as the dict-page `TranslationKeyCell` and the config-builder key selectors. The suggestion is **baseline-seeded**: `EntityFormSurface.buildInitial` computes it via `i18nKeySuggestionFor` so an empty i18n field opens pre-filled WITHOUT tainting the form (the suggestion is the initial value, not a post-mount write). List cells render the resolved-translation badge (icon + `$t`, raw-key tooltip); filter surface maps to contains-text. |

## `table` — `EntityListTable` options

| Prop | What it does → enables on FE |
|------|------------------------------|
| `default_view` | Initial view: `table`/`cards`/`cards_list`. |
| `default_sort` | `{key, dir}` when no user sort is stored. |
| `default_page_size` / `page_size_options` | Initial page size + dropdown values. |
| `row_custom_actions` | Non-standard row CTAs — synthesized from `RpcRoute.entity_op`; authored entries are per-`action_name` overrides only (`icon`, `color`, `visible_on`, `row_key`, `translation_key`, `confirm_key`, `disabled_when_deleted`, `required_permission`). |
| `bulk_custom_actions` | Selection-toolbar CTAs — same `entity_op` synthesis; `requires_selection`, `require_step_up`, `confirm_key`. |
| `filter_presets` | Mutually-exclusive WHERE presets — toolbar `button_group` (icon-only, `icon` required per option) or `combobox`. Exactly one option active, `where:[]` is the "all" escape, `default_option` required; conditions AND into every `/list` request. |

## `actions` — the capability contract

Derived from the registered route table (`deriveEntityActions`). The
array **always** contains the full standard vocabulary — a missing route
produces `{ enabled: false }`, never an absent op:

`list`, `meta`, `get`, `create.single`, `update.single`, `update.bulk`,
`delete.single`, `purge.single`, `restore.single`, `read.audit`, `export`,
`delete.bulk`, `restore.bulk`, `duplicate.bulk`

Each entry carries:

| Field | What it does → enables on FE |
|-------|------------------------------|
| `op` | Canonical op name (or the last path segment for non-standard routes). |
| `permissions` | Declared non-sentinel permissions (OR) — filtered client-side against the session. |
| `sentinel` | `_public`/`_authenticated_user`/`_authenticated_admin` gate. |
| `enabled` | `false` hides the CTA **everywhere** — the single capability mechanism, no parallel flags. |
| `endpoint` | `{method, path}` of the backing route — writes dispatch here, not to a guessed convention (`:param` filled from row fields). Absent → entity convention base. |
| `label_key`/`icon`/`color` | CTA chrome override — `color` is the `ActionColor` closed enum (drives icon AND label together); semantic icons (`exec-start`/`exec-stop`) bind their color by contract. |
| `confirm_key`/`busy_key` | Confirm-dialog message / in-flight label overrides (soft-delete-as-disable copy). |

## Form placements — `page_props.form`

`kind:"create"|"detail"` entity forms declare `fields` — the ORDERED
placement list (only declared keys render). A placement positions a field
the entity owns; it never redefines type/validation (those come from
`meta.columns`).

Without an authored form the record sheet rides the **synthesized**
fallback — every served column minus the never-a-field flags: `hidden`
(not served), `audited` (accordion-only), `managed`, `kind` virtuals,
uid/`version`. `default_visible:false` governs the **list** only — a
computed column that must stay out of the form carries `audited` or
`hidden`, never just `default_visible` (the `sequence` revive-axis leak
this rule exists for). Cross-field rules attach via `meta.form.validators`.

| Prop | What it does → enables on FE |
|------|------------------------------|
| `key` | Column key — must exist in `meta.columns` (drift fails loudly). |
| `col` / `span` | `grid-column` start / span — `span:2` = full-width row. |
| `row` / `row_span` | `grid-row` start / span — full-height column slots (e.g. a builder beside static fields). |
| `section` | Section id grouping fields under a shared i18n header. |
| `default_value` | Create-surface **initial value prefill** — the per-surface override in the default chain (`placement.default_value` > authored `MetaColumn.default` > `@Column({defaultSql})` constant > type fallback). Create-only: update surfaces read the record, never a default. |
| `placeholder_key` | i18n key of the control placeholder. |
| `required` | May only **loosen** the class-derived `nullable` to optional — never tighten past the physical contract. |

Placement keys are a **closed set** — `widget`/`options_source`/
`allow_create` are column semantics (rejected as "moved"), `kind`/
`managed`/`audited`/`uid`/`hidden` are served facts (rejected as
"served"). `validators` names closed-vocab cross-field rules the host
implements.

## Search behavior

The default "all fields" search covers **visible ∩ searchable ∩
text-physical** columns:

- A hidden-by-default column (`uuid`) is **not** searched until the user
  makes it visible.
- The scope selector lists **all** searchable columns — an explicit
  selection always wins.
- Non-text columns never enter an `ILIKE` scope.

## Writing a new meta

Annotate the static object with `EntityMeta` — the closed type rejects
unknown properties and missing `display_field` at compile time:

```ts
import type { EntityMeta } from "@primebrick/core";

export const ticketMeta: EntityMeta = {
  entity: "ticket",
  translation_key: "ticket",
  uid: "uuid",
  display_field: "title",
  // display_name omitted — materialized as "${title}" by assembleMeta
  // uuid/created_at/updated_*/version/deleted_* are NOT declared — they are
  // auto-derived (hidden-but-selectable). Author them only to change
  // visibility/order.
  columns: [
    { key: "title", label_key: "acme.entities.ticket.fields.title", type: "text", order: 0, sticky: true, hideable: false },
  ],
  table: {
    default_sort: { key: "created_at", dir: "desc" },
    default_page_size: 25,
    page_size_options: [10, 25, 50, 100],
  },
};
```
