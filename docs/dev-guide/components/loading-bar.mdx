# LoadingBar

`src/lib/components/ui/loading-bar/loading-bar.svelte`

## Purpose

Indeterminate loading indicator for async operations with no progress
value — entity-list reloads, sheet loads, route transitions. It renders a
**scanner-comet** animation: a ~25%-wide luminous blob sweeping
left→right→left across a muted track (the "Larson scanner" made famous by
Knight Rider's KITT).

## Effect anatomy

Two stacked layers inside the `rounded-full` muted track:

- **Underlay** — the original full-width brand gradient
  (`#38bdf8 → #6366f1 → #8b5cf6`) panning via `animate-gradient-pan`, at
  `opacity: .15`: ambient motion, never the primary signal.
- **Comet** — `.kitt-comet`: a symmetric gradient blob
  (`transparent → sky → indigo → violet → transparent`) with an indigo
  `box-shadow` glow. It sweeps via `translateX` +
  `animation: kitt-scan .85s cubic-bezier(.45,0,.55,1) infinite alternate`
  — `alternate` produces the ping-pong and the symmetric ease-in-out
  produces KITT's signature deceleration at both edges. The same
  "bright head + soft wings" technique used by the animated destructive
  input border, transposed from a 2D perimeter to a 1D track.

`prefers-reduced-motion` collapses both animations and renders the comet
as a static full-width gradient.

## Origin

**Custom** — Primebrick-built primitive. Variants via
`tailwind-variants` (`loadingBarVariants`).

## Usage

### Default (xs, muted)

```svelte
<script lang="ts">
  import { LoadingBar } from "$lib/components/ui/loading-bar";
</script>

<LoadingBar />
```

### Larger size

```svelte
<LoadingBar size="sm" />
```

### Inline at the top of a card

```svelte
<div class="rounded-xl border">
  <LoadingBar />
  <div class="p-4">Card content…</div>
</div>
```

## Props

Full prop table: see [API reference — loadingbar](/docs/dev-guide/api-reference#loadingbar).

Key props:

- `size` (`"xs" | "sm"`, default `"xs"`) — track height.
- `variant` (`"muted"`, default `"muted"`) — track background.
- `barClass` (`string`) — extra classes for the gradient underlay layer.
- `class` — extra classes for the track.

## Consumers

- Entity-list reload strip (`data-testid="elt-reload-strip"`) — see
  [Entity list table — reload UX](/docs/dev-guide/components/entity-list-table#reload-ux)
- `EntityRecordSheet`, `ServiceRecordPanel`, `TableBody`, `CardViewRenderer`,
  `EntityDictPage` — inline loading slots.
