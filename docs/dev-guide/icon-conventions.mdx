# Icon Conventions

Primebrick assigns **one canonical Lucide icon per semantic action**. Always
check this map before importing an icon — if the action is listed, use its
icon (or the component that owns it).

## Canonical map

| Action | Icon | Notes |
|--------|------|-------|
| Refresh / reload | `RefreshCw` | Via the `RefreshButton` component — never hand-rolled |
| Clear / reset | `Eraser` | Clear an input value, reset filters — **not** close |
| Close / dismiss / remove | `X` | Sheet close, chip remove — **not** clear |
| Restore deleted | `trash-restore` | Undo soft-delete — authored glyph in `CUSTOM_ICONS` (`@primebrick/ui`), rendered via `DynamicIcon name="trash-restore"` on every restore surface. `RotateCcw` stays the **local revert/undo** glyph (dict row revert, sheet head reset) |
| Local revert / undo | `RotateCcw` | In-place reverts that are NOT soft-delete restores (dict row revert, sheet-head reset) |
| Delete | `Trash2` | |
| Edit | `Pencil` | |
| Add / create | `Plus` | |
| Search | `Search` | |
| Filters | `Funnel` | |
| Show / hide secret | `Eye` / `EyeOff` | |
| Copy | `Copy` | Duplicate/clone CTAs — pairs with the `violet` action color (clone semantic: `duplicate.bulk` serves `color:"violet"` + `icon:"copy"` by default; the same hue marks `CLONE` version-history rows) |
| True / false | `CircleCheck` / `CircleX` | Never `CheckCircle` / `XCircle` |
| Warning / empty | `TriangleAlert` | Never the `AlertTriangle` alias |
| Loading | `Hourglass` | Watermark empty-state pattern |
| In-flight spinner | `LoaderCircle` | With `animate-spin` |
| Dropdown caret | `ChevronDown` | |
| AI capability | `BrainCircuit` | |
| Docs / user guide browser | `BookOpenText` | Topbar docs CTA and `shell.docs` panel header |
| UUID / record identity | `FileKey` | `format:"uuid"` fields and the record-sheet uid badge. `Fingerprint`/`FingerprintPattern` are the passkey/WebAuthn domain — banned on entity-uuid surfaces |
| Record sheet entity icon | singular variant of the authored list icon | A record shows ONE row: `users`→`user`, `users-round`→`user-round` via `RECORD_ICON_VARIANTS` in `EntityRecordSheet.svelte`. Icons without a declared pair render the authored glyph unchanged — extend the map, never guess |

**Entity list icons must be unique per entity family.** The record sheet
derives its header icon from the authored list/nav icon — two entities
sharing a glyph produce indistinguishable ref sheets. Vary the icon
family (`users` for `user_profile`, `users-round` for `customer`), never
two entities on the same glyph. Non-entity leaves (module roots,
pipelines, dashboards) may reuse icons freely — they never feed the
singular-variant map.

## RefreshButton

`src/lib/components/ui/refresh-button/`

The single canonical refresh CTA. Ghost `sm` button, `RefreshCw` icon that
spins while `loading`, label `Refresh` hidden below `lg`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `onclick` | `() => void` | required | Refresh action |
| `loading` | `boolean` | `false` | Spins the icon and disables the button |
| `disabled` | `boolean` | `false` | Extra disable condition |
| `compact` | `boolean` | `false` | Smaller, muted, uppercase-label chrome — for refresh CTAs pinned inside card wrappers (e.g. a section card's top-right corner) |
| `label` | `string` | `"Refresh"` | Override accessible label |
| `testid` | `string` | — | `data-testid` |

```svelte
<script>
  import { RefreshButton } from '$lib/components/ui/refresh-button';
</script>

<!-- toolbar context -->
<RefreshButton onclick={reload} loading={reloading} />

<!-- inside a card wrapper, pinned top-right -->
<div class="relative rounded-lg border p-3">
  <RefreshButton compact onclick={reload} loading={reloading} />
  …card content…
</div>
```

`Toolbar` also exposes a `refresh` prop that renders this same atom — pass
`refresh={{ onclick, loading }}` rather than rendering it yourself.
