# Slider

`src/lib/components/ui/slider/slider.svelte`

## Purpose

A single-value range slider for bounded numeric settings (e.g. temperature
0–2 step 0.1). `value` is a bindable `number`.

## Origin

**Primebrick wrapper** over the `bits-ui` `Slider` primitive
(`Slider.Root`/`Range`/`Thumb`), styled after the shadcn-svelte™ slider
(track `bg-primary/20`, filled `Range`, bordered thumb).

## Usage

### Basic

```svelte
<script lang="ts">
  import Slider from "$lib/components/ui/slider/slider.svelte";
  let temperature = $state(0.1);
</script>

<Slider bind:value={temperature} min={0} max={2} step={0.1} />
```

### Slider + numeric Input (nullable "inherit" pattern)

When `null`/empty means "inherit a default", pair the slider with a numeric
`Input`: an empty input shows `placeholder="inherit"` while dragging the
slider writes the override value.

```svelte
<script lang="ts">
  let temperature = $state(""); // '' = inherit
  let tempSlider = $state(0);
  $effect(() => {
    tempSlider = temperature.trim() !== '' ? Number(temperature) : 0;
  });
</script>

<div class="flex items-center gap-2">
  <Slider
    bind:value={tempSlider}
    min={0}
    max={2}
    step={0.1}
    class="flex-1"
    onValueChange={(v) => (temperature = String(v))}
  />
  <Input type="number" step="0.1" min="0" max="2"
    bind:value={temperature} placeholder="inherit" class="w-16" />
</div>
```

Canonical use: `AiCerebellumPanel` temperature field
(`src/lib/shell/sheets/panels/AiCerebellumPanel.svelte`).

## Props

| Prop | Type | Default | Notes |
|---|---|---|---|
| `value` | `number` (bindable) | `0` | current value |
| `min` / `max` | `number` | `0` / `100` | range bounds |
| `step` | `number` | `1` | granularity |
| `disabled` | `boolean` | `false` | dims the control |
| `onValueChange` | `(v: number) => void` | — | live drag callback (bits-ui passthrough) |
| `class` | `string` | — | appended to Root |
